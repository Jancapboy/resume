📱 两层架构：原生壳负责「能力」，Web 内核负责「体验」

这个 App 的核心判断是不要在原生侧写业务：原生壳只承担网络桥、加密存储、文件分享、桌面挂件这四件 Web 做不到的事；界面、状态、搜索全部留给零依赖的 Web 内核。这样一份对话逻辑能同时跑在 Android、iOS 与浏览器三处。

🔌 桥接层：窄接口 + 硬件级密钥保护

Web 与原生之间的桥是整个架构的攻击面，因此接口刻意做窄，敏感数据一律不经过 Web 侧明文。

桥接口

17 个受控入口

Bridge.java 用 17 个 @JavascriptInterface 方法承载网络请求、文件保存、语音、挂件等能力，接口清单显式可查，而不是开一个万能 invoke。

  • 网络请求与中止分离（request / abort）
  • 密钥读写与普通配置分开成两个入口
  • 挂件数据、悬浮窗状态各自独立
密钥保护

KeyStore + AES/GCM

Crypto.java 用 AndroidKeyStore 里的 AES 密钥做 AES/GCM/NoPadding 加密，密文落 SharedPreferences。密钥本身不出硬件，密文离机不可解。

  • 密钥材料由 Keystore 生成，不进 App 存储
  • GCM 带认证标签，密文被篡改会直接失败
  • 浏览器版退化为 localStorage，边界显式标注
悬浮窗

636 行的独立服务

OverlayService.java 单独成进程承载悬浮聊天窗，含左右吸边布局与收起策略，是原生侧最复杂的一块，因此独立成文件便于单独回归。

  • 聊天窗与主界面共享同一份会话状态
  • 自动收起避免长期遮挡他人屏幕
  • 失败时降级到通知而非崩溃

🎙️ 语音与情绪：三路 TTS + 受限 ASR + 规则情绪

语音这块最容易做成「调用一个 API」。这里的做法是三条 TTS 路线各有独立计费口径、ASR 明确设限、情绪用规则而非模型 —— 每一层的边界都能在代码里指出。

🔧 三条 TTS 路线与 ASR 硬限制

路线 / 约束 实现要点
TTS · system 系统 TTS，免费、离线、不支持情绪参数
TTS · deepseek 官方 stella / tide 两个音色，无情绪参数
TTS · qwen qwen-audio-3.0-tts-plus，endpoint 可配，支持情绪指令
计费 按各路线独立单价（元/万字符）记，HUD 每轮显示本轮花费
ASR 格式 仅 16-bit PCM WAV（8000/16000/22050/24000/32000/44100/48000 Hz）或 Ogg Opus
ASR 上限 体积 ≤8 MiB，时长 ≤120 秒，超限分别报 too_large / too_long

💡 上限写死在代码里：maxBytes: 8 * 1024 * 1024 与 maxDurationMs: 120000 是硬常量，录音满 120 秒自动停并提示分段，而不是等服务端拒绝后才报错。

情绪

6 标签规则推断

emotion.js 用 6 个中文标签（温柔 / 开心 / 认真 / 安慰 / 俏皮 / 中性）做规则推断，输出包含 warmth、energy、pace 与 evidence，结论可回溯到命中的词。

  • 标签白名单外的取值统一回落为中性
  • 返回体带 evidence，不给黑箱结论
  • 与 TTS 情绪参数解耦，缺参数不影响发声
上下文

三层上下文而非堆 token

context.js 组三层：system 放身份与按日期检索到的往事、最近 12 轮原文、更早轮次的滚动摘要或首句降级。预算默认 32000 tokens，超限时先砍最老整轮再减回忆条数。

  • meta 回传 truncated / droppedTurns / tokensEstimate，可审计
  • 回忆只注入 system，不混进 user 消息
  • 断点续写不注入回忆，避免打断语义
检索

本地倒排索引

memory.js 为每条消息打真实日期标记，跨会话建中文二元组 + 拉丁词的倒排索引并带 idf 与覆盖度打分，recall() 返回带日期、标题、片段与分数的结果。

  • 数据不出手机，不依赖外部服务
  • 按分数降序、日期不串桶
  • 长历史也能定位到具体那天的对话

高危 1

可调试包 + 远程调试

正式包常开 WebView 远程调试、且 APK 标记为 debuggable —— 真机一条 window.DSHttp.getSecret({name:"deepseek_api_key"}) 就能读出明文密钥。门槛极低，判为高危。

  • 结论：必须关闭 release 包的 isInspectable
  • debuggable 标记不得进入发布产物
高危 2

run-as 可整目录拷走

拿到 adb 的人可用 run-as 整目录拷走 app_webview/（IndexedDB 里的对话正文）与 shared_prefs/（密钥密文，离机不可解）。

  • 对话正文属明文数据，需单独加密
  • 密钥密文因走 Keystore 而不可解
中危 / 低危

桥接口未做白名单

getSecret / setSecret 对任意名字开放、request 可向任意 URL 带任意 header 外发（明文 http 被系统策略拦下，https 不受限）；iOS 侧 isInspectable 无条件开、Keychain 全量快照以 forMainFrameOnly: false 注入每个 frame。

  • 需按名字白名单化密钥读写
  • Android openExternal 需补 scheme 白名单
  • 开发服务器 /__proxy 是开放代理，仅本机 dev 暴露

🧾 其它可验证的细节

导入

深链导入真分享

从 DeepSeek 分享链接导入，解析出标题 / 条数 / 引用数 / 首条内容后先预览再落库，支持系统分享与深链两种入口。

  • Android 14 模拟器 1080×1920 实测：导入 8 条消息 / 52 条引用
  • 可搜索、可续聊、可导出 .md / .json
断点

断点续写与退避重试

流式中断时已生成文本立即落库并把消息置为 paused，顶部显示「已中断 · 已生成的内容已保留」，可从断点续写或整条重生成。

  • 续写走官方 beta prefix completion，模型从已写文本无缝续
  • 网络 / 429 / 5xx 自动退避 0.8s / 1.8s / 4s（±20% 抖动），最多 3 次
  • App 重启后 recover() 扫描 pending，10 分钟内的请求可继续
计费

花费可对账

HUD 每轮显示输入（区分缓存命中）、输出（单列思考 tokens）与本轮花费，按官方峰谷价 + 缓存命中价计价，默认 $1 = ¥7.2 且可在设置里改。

  • 实测 ↑2.21k ↓1.35k ¥0.0165 与手算一致
  • 峰值为谷值 ×2（UTC 周一至周五 01:00–04:00、06:00–10:00）

原则 1
