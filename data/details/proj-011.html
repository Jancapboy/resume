🏗️ 三级架构总览

Level 1 · 入门

LangChain 线性链

PromptTemplate | LLM | StrOutputParser RunnablePassthrough.assign()

LCEL 管道语法、线性流程、上手快。代码量少，无状态共享。

  • LCEL 管道式编程，Runnable 组合
  • 串行执行，低延迟（0.14~0.43s）
  • 适用：简单问答、基础 RAG、单步工具调用
Level 2 · 进阶

LangGraph 有状态图

StateGraph add_node add_edge add_conditional_edges MemorySaver

图结构 + 状态管理 + 自我反思循环（Review-Revise）+ 检查点持久化，输出质量提升 32%~60%。

  • Annotated[type, reducer] 状态合并策略
  • MemorySaver 支持状态回溯与断点恢复
  • 适用：复杂决策、多轮迭代、需要状态持久化
Level 3 · 生产级

多智能体 DAG

LangGraph DAG 编排 专业化 Agent ThreadPoolExecutor MemorySaver

多角色 Agent 分工协作，DAG 拓扑排序 + 并行执行 + 质量闭环，平均质量 8.47 分。

  • 4 专家并行审查 / 双源并行检索
  • 质量闭环（审查 Agent 把关）
  • 适用：复杂任务分解、多角色协作、生产级应用

5-20 步
